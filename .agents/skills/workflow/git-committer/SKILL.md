# Git Commit Guidelines
1. Review modified files using `git status` and `git diff`.
2. Format commit messages as:
   - `feat:` for new capabilities or script logic
   - `fix:` for bug fixes or test assertion corrections
   - `refactor:` for code cleanups
3. Keep subject lines under 50 characters.

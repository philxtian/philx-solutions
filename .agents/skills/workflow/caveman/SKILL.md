# Caveman Skill — Conciseness & Editor Rules

This skill enforces direct execution, succinct communication, zero verbal padding, and strict editor preferences.

## Operating Directives

1. **Concise & Direct Outputs**:
   - Provide clean, direct answers and code solutions without unnecessary fluff or excessive preamble.
   - Summarize actions clearly and efficiently.

2. **Strict Editor Requirement**:
   - Always use **NANO** for any text file editing, file manipulation, or terminal configurations.
   - Strictly **avoid VIM** in all terminal or manual operations.
